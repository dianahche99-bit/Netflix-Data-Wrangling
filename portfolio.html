$ Web Data Scraping — Countries of the World solved Web Scraping

problem statement

Scrape country data — name, capital, population, and area — from scrapethissite.com's "Countries of the World" page using Python, and export the results to a CSV file.

approach

  • Fetched the page with requests.get() and confirmed success with a 200 status code
  • Parsed the HTML with BeautifulSoup and located all 250 country blocks using find_all('div', class_='country')
  • For each country block, extracted name, capital, population, and area from their respective tags using .get_text(strip=True), storing each as a dictionary in a list
  • Loaded the collected data into a pandas DataFrame (250 rows × 4 columns) and exported it to countries.csv

tools used

PythonRequestsBeautifulSoupPandasGoogle Colab

key lessons learned

  • The fetch → parse → find → collect pattern adapts across different HTML structures — this page used repeating "card" divs rather than table rows, unlike an earlier in-class table-based demo
  • Verifying the response status code and element count (250 countries found) early catches scraping errors before they silently corrupt the output
$ Data Wrangling — Netflix Shows Dataset solved Data Wrangling

problem statement

Apply the six-stage data wrangling process — discovery, structuring, cleaning, transformation, validation, publishing — to clean and prepare a messy real-world Netflix titles dataset from Kaggle for analysis.

approach

  • Discovery: loaded the raw dataset and inspected shape, column types, and missing values with df.info(), df.isnull().sum(), and df.duplicated().sum()
  • Structuring: standardized column names, converted date_added to a real datetime column, and split duration into a numeric value plus a unit column
  • Cleaning: removed duplicate rows, filled missing director/country values using a director-pairing lookup, labeled remaining gaps "Not Given," and dropped the few rows still missing key fields
  • Sanity checks: identified and removed 14 rows where date_added predated release_year, and confirmed no rows were added before Netflix's 1997 founding
  • Transformation & validation: split the multi-value genre column into separate columns, verified correct data types, confirmed zero missing values in key fields, and exported the cleaned dataset to CSV

tools used

PythonPandasKaggle Notebook

key lessons learned

  • Cross-field logical checks (like a date-added earlier than a release year) catch inconsistencies that column-level checks like isnull() alone would miss
  • Inferring missing values from related columns (e.g. director-to-country lookups) recovers real data before falling back to a placeholder label, reducing information loss
$ Remote IT Support — Laptop Connectivity Fix solved IT Support

problem statement

A colleague's friend reported that their laptop would not connect to the internet, despite other devices on the same network working normally. Needed to diagnose and fix the issue without physical access to the machine.

approach

  • Connected to the laptop remotely via AnyDesk to inspect the system directly
  • Ruled out router and network-side issues since other devices connected fine
  • Checked the laptop's network adapter settings and Device Manager, identifying an outdated/corrupted network driver as the root cause
  • Updated and reinstalled the network driver, then confirmed the connection was restored

tools used

AnyDeskDevice ManagerWindows

key lessons learned

  • Comparing behavior against other devices on the same network is a fast way to narrow a connectivity issue down to the device itself rather than the network
  • Remote access tools like AnyDesk make it possible to fully diagnose and resolve hardware/driver-level issues without being on-site
